# Amazon.in Clone

A responsive clone of Amazon.in homepage built using HTML and CSS.

## Live Demo
https://officialrikdutta-blip.github.io/Amazon-clone/Amazon%20clone/index.html

## Features I included
- Responsive Navbar with logo, search and cart
- Hero banner for "Great Freedom Sale"
- Product sections: Smartphones, Amazon Business, Bulk Deals, Top Brands
- Full footer with links like About, Careers, Help

## Tech Stack
HTML, CSS

Built this to practice responsive web design and layout.
